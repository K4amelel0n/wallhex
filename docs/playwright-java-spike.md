# Playwright for Java DAST crawler spike

Tracks [issue #1](https://github.com/K4amelel0n/wallhex/issues/1).

## Question

Can Playwright for Java support a DAST crawler that discovers reachable surfaces in both static and dynamic web applications?

## Investigation

- [ ] Evaluate discovery of links, forms, and other navigable elements on static pages.
- [ ] Evaluate JavaScript-rendered content and client-side navigation.
- [ ] Check authentication, session isolation, and browser context management.
- [ ] Check request and response inspection and navigation controls useful to a crawler.
- [ ] Build a small proof of concept against representative static and dynamic pages.
- [ ] Record limitations, operational costs, and an adoption recommendation with sources.

Replace this outline with the findings, proof-of-concept results, and a recommendation before the PR is ready for review.
